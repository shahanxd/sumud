# game/assets/audio

Two sources, one contract. **Generated world sound** (since 1 October 2026, lock G-01): the files listed in `generated.json` were made with ElevenLabs sound effects (`eleven_text_to_sound_v2`) from the prompts in that manifest and shaped by `tools/eleven.py` (trim, slice into variants, crossfade loops, levels, dither). **Synthesised**: `drone_hum_loop`, `rumble_loop`, `ringing` (they follow a parameter in real time) and `roof_breath_loop` (the placeholder for the friend's recording) come from `tools/audio.py` (numpy and scipy, fixed seeds). No instruments, nothing that imitates one, no voices. Regenerate synthesised files with `.venv/bin/python tools/audio.py --only <names>` (without `--only` it overwrites every file, so run `tools/eleven.py` again afterwards; its takes are cached). Verify everything with `tools/audio.py --check`. Every generated file is a draft until the founder has heard it in the game.

`roof_breath_loop.wav` is a PLACEHOLDER for the friend's recorded vocal pad: it is breath and air through moving formants, with no fundamental, and it is listed as a placeholder in docs/rights.md. Replace it before any build leaves the machine.

Format: 48 kHz, 16-bit PCM, TPDF-dithered. Loop files are exactly periodic; the file carries one extra frame (a copy of the first) and a `smpl` chunk looping (0, N], which Godot reads under its default "Detect From WAV" import setting, so no .import edit is needed for looping. Godot 4.7's default WAV import compresses to Quite OK Audio; set `compress/mode=0` in the .import of any file that must stay PCM (the strike is the candidate).
