# game/assets/audio

Every file in this folder was generated by `tools/audio.py` (numpy and scipy, fixed seeds). There is no recorded, downloaded or AI-generated material here: everything is world sound synthesised from noise, impulses, resonances and envelopes. No instruments and nothing that imitates one. Regenerate with `.venv/bin/python tools/audio.py`; verify with `--check`.

`roof_breath_loop.wav` is a PLACEHOLDER for the friend's recorded vocal pad: it is breath and air through moving formants, with no fundamental, and it is listed as a placeholder in docs/rights.md. Replace it before any build leaves the machine.

Format: 48 kHz, 16-bit PCM, TPDF-dithered. Loop files are exactly periodic; the file carries one extra frame (a copy of the first) and a `smpl` chunk looping (0, N], which Godot reads under its default "Detect From WAV" import setting, so no .import edit is needed for looping. Godot 4.7's default WAV import compresses to Quite OK Audio; set `compress/mode=0` in the .import of any file that must stay PCM (the strike is the candidate).
