# SUMUD

A 2D narrative adventure about one family in Gaza, told over ten days. A game about staying.

Made by shahanxd. Built in Godot 4.7 with every asset generated by scripts.

## Layout

- `game/` the Godot project (open `game/project.godot`)
- `tools/` Python generators for buildings, kites, tatreez, character rigs, audio
- `assets/` generated output, committed so the project opens without running anything
- `docs/` the design document and the execution plan
- `tests/` bot playthroughs and unit tests
- `bin/` the Godot editor binary (not committed, see below)

## Setup on Windows

1. Download `Godot_v4.7.2-stable_win64.exe.zip` from the official Godot releases and unzip it into `bin/`.
2. Run the headless smoke test:

```
bin/Godot_v4.7.2-stable_win64_console.exe --headless --path game -s res://tests/smoke.gd
```

3. Open the editor: `bin/Godot_v4.7.2-stable_win64.exe --path game`
